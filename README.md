# 🤖 Multi-Tool Telegram Bot

> **Greetings!** I am a coder with a disability and I'm learning how to program. 👨‍🦽💻
> This bot is developed strictly for educational purposes to practice API integration and web scraping.

## 📌 About
An educational Telegram bot that combines three useful features: weather monitoring, cryptocurrency tracking, and basic web scraping. This project is part of my learning journey in Python development.

## 🚀 Key Features
* **🌤 Weather:** Real-time weather updates for any city.
* **₿ Cryptocurrency:** Instant Bitcoin to USD exchange rate.
* **🔎 Web Scraping:** Extracting headers from websites to understand HTML structures.
* **🆘 Support:** Interactive help menu for easy navigation.

## 🛠 Commands
| Command | Description | Example |
| :--- | :--- | :--- |
| `/weather` | Weather in a specific city | `/weather London` |
| `/btc` | Current Bitcoin price | `/btc` |
| `/parse` | Extract headers from a URL | `/parse https://example.com` |
| `/help` | List of available commands | `/help` |

# 🤖 Multi-Tool Telegram Bot

> **Приветствую!** Я кодер-инвалид и учусь программировать. 👨‍🦽💻
> Данный проект создан сугубо в учебных целях для отработки навыков работы с API и парсинга сайтов.

## 📌 О проекте
Учебный Telegram-бот, объединяющий в себе три полезные функции: мониторинг погоды, отслеживание курса криптовалют и базовый веб-парсинг. Это мой практический шаг в освоении Python и асинхронного программирования.

## 🚀 Основные возможности
* **🌤 Погода:** Получение актуальных метеоданных в реальном времени.
* **₿ Криптовалюта:** Мгновенный запрос текущей стоимости Bitcoin.
* **🔎 Парсинг:** Извлечение заголовков с веб-страниц для изучения структуры HTML.
* **🆘 Помощь:** Навигация по всем доступным функциям.

## 🛠 Команды бота
| Команда | Описание | Пример |
| :--- | :--- | :--- |
| `/weather` | Погода в указанном городе (EN) | `/weather Moscow` |
| `/погода` | Погода в указанном городе (RU) | `/погода Москва` |
| `/btc` | Актуальный курс Bitcoin к USD | `/btc` |
| `/parse` | Получить заголовки с сайта | `/parse https://example.com` |
| `/help` | Список всех команд | `/help` |
